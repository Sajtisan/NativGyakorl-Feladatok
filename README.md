## Követelmények

- A megoldás C++20 nyelven, a `solution` névtérben készüljön.
- Csak terminál használható, IDE nélkül.
- Fordítási hiba vagy figyelmeztetés esetén a beadás **0 pont**.
- A hibakereső feladat kezdőkódja szándékosan hibás.
